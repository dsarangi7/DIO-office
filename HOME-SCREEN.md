# Add DIO Office to Home Screen

Public URL (only this one): **https://dsarangi7.github.io/DIO-office/**

Bookmark and install from that exact address. The path is case-sensitive — capital **DIO-office**. `https://dsarangi7.github.io/dio-office/` is a permanent GitHub Pages 404.

## Phone — iOS Safari

1. Open the URL in Safari.
2. Tap **Share** (square with arrow).
3. Tap **Add to Home Screen**.
4. Confirm the name (**DIO Office**) and tap **Add**.

## Phone — Android Chrome

1. Open the URL in Chrome.
2. Tap the **⋮** menu.
3. Tap **Install app** or **Add to Home screen**.
4. Confirm.

## Laptop — Chrome / Edge

1. Open the URL.
2. Click the **install** icon in the address bar (or menu → **Install Dibya’s Intelligence Office…**), **or**
3. Bookmark **https://dsarangi7.github.io/DIO-office/** (star / Ctrl/Cmd+D). The bookmark must use capital **DIO-office**.

After install, the app opens standalone (no browser chrome) with the dark charcoal theme.
